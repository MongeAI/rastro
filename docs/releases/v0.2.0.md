```bash
npx @mongeai/rastro@0.2.0 .
```

## 🧱 Architecture rules that check themselves

Write down who may depend on whom in a `rastro.rules.json`, and Rastro proves every violation with the file and line that causes it.

```json
{
  "rules": [
    {
      "name": "The UI does not touch the database",
      "from": "src/ui",
      "deny": ["src/db", "pkg:pg"]
    },
    { "name": "Pure domain", "from": "src/domain", "allow": ["pkg:zod"] },
    { "name": "No import cycles", "noCycles": true }
  ]
}
```

- **`rastro check --init`** writes the rules your code already follows: the layering between your main folders (also between the packages of a monorepo), no import cycles, production code not importing tests. Today's architecture is locked in with one command.
- **`rastro check`** lists each rule and its violations. With `--since main`, only what the branch introduced fails, so existing debt never blocks anyone. Exit codes work like a linter's.
- **In every pull request** the Action comments the new violations and fails the job (`fail-on-violations`).
- **In the map**, a new **Rules** tab draws the offending dependencies in red, live with `--watch`.
- **Your AI agent** calls `rastro_check` before saying it is done.
- **Only proven relationships fail.** Calls that only _may_ reach a forbidden file, through an interface, are listed apart.

![rastro check in the terminal: one new violation with its file and line](https://github.com/MongeAI/rastro/raw/v0.2.0/docs/assets/en/check.png)

## 🤖 Rastro for AI agents: `rastro mcp`

A Model Context Protocol server for Claude Code, Cursor, VS Code and any MCP client. It has eight read-only tools: overview, search, entity, references, impact, check, path and routes. Every answer carries `file:line` evidence and keeps what is **proven** apart from what is only **possible**. The graph is re-analyzed after every edit, and it has no runtime dependency.

```bash
claude mcp add --transport stdio rastro -- npx -y @mongeai/rastro@0.2.0 mcp
```

![A real Claude Code session: rastro_check finds the import that breaks a rule and the agent proposes the fix](https://github.com/MongeAI/rastro/raw/v0.2.0/docs/assets/en/mcp.png)

## 🧭 Rastro in every pull request

`uses: MongeAI/rastro@v0.2.0` comments on each pull request with:

- what it changes;
- what it **possibly broke**: an import of a deleted file, a name that is no longer exported, a method that is gone;
- the rules it breaks;
- the HTTP routes involved;
- **the tests to run**.

It also attaches the offline interactive map. The same report is in the terminal with `rastro impact`. With `--tests`, you get only the affected test files, ready to pipe into your test runner.

![The Rastro comment on a pull request](https://github.com/MongeAI/rastro/raw/v0.2.0/docs/assets/en/pr-comment.png)

## Also new

- **Changes tab.** `--changes` or `--since main` shows what changed, who depends on it (by distance), the routes involved and the tests to run, and highlights the blast radius on the map.
- **How does A reach B?** The shortest chains of proven calls, imports and inheritance, each step with its evidence.
- **Insights.** The most called functions, the orchestrators, the central files, the most coupled folders and possibly unused code.
- **Live mode** (`--watch`). Re-analysis on save, and the open map updates without losing your selection.
- **More frameworks.** Next.js (App and Pages Router), Fastify, Hono and NestJS routes, plus Express mount prefixes. The full path is shown only when it can be proven.
- **Export and compare.** Mermaid, DOT, GraphML and a single-file offline HTML report; `rastro compare a.json b.json`.
- **Navigation.** A command palette (<kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>K</kbd>), arrow keys between nodes, a minimap, a breadcrumb and a shortcuts list (<kbd>?</kbd>).
- **English and Portuguese** in the interface and the CLI.
- **Faster.** Analysis is about 37% faster. The files level of a 5,000-file project opens in seconds, and the symbols level of a large map is about 3× faster.

## Upgrading

- **Data format.** Graphs saved by 0.1 still open: `schemaVersion` stays `0.1.0` and 0.2 only adds optional fields.
- **Stricter command line.** Options that do not apply to a command are now rejected with an explanation instead of being silently ignored.
- **Git safety.** `--changes`/`--since` run only read-only git commands and refuse a repository config that defines commands (`--trust-git-config` to override).

## Quality

- **Tested on real projects.** Rastro was checked against 8 open-source projects (Express, Fastify, Hono, NestJS, Vite, tRPC, Excalidraw and a Next.js app), and every fix carries a regression test.
- **Test suite.** 538 unit tests and 17 interface tests in headless Chrome run on every push, along with benchmarks of 100, 1,000 and 5,000 files.
- **Rastro checks itself.** Its own `rastro.rules.json` (core is the foundation, graph and the web map run in the browser) runs in CI.
