**Rastro 0.2.1: works out of the box in GitHub Actions.**

```bash
npx @mongeai/rastro@0.2.1 .
```

- 🔧 `rastro impact`, `rastro check --since main` and `--changes`/`--since` no longer refuse a repository just because its git config has an `include.path` or `includeIf`. The current `actions/checkout` stores credentials that way, so running Rastro directly in a workflow failed unless you passed `--trust-git-config`. Included files are still inspected: if one defines a command (`core.pager`, `diff.external`, `core.fsmonitor`…), Rastro still refuses to run git. The Rastro Action was not affected.
- 📦 `uses: MongeAI/rastro@v0.2.1` installs this version by default.

Everything else is as in [0.2.0](https://github.com/MongeAI/rastro/releases/tag/v0.2.0).

---

<sub>🇧🇷 **Português:** a 0.2.1 deixa o `rastro impact` e o `rastro check --since main` funcionarem direto num workflow do GitHub Actions: o `include`/`includeIf` que o `actions/checkout` usa para as credenciais não é mais recusado (os arquivos incluídos continuam conferidos, e um comando perigoso neles ainda é recusado). A Action do Rastro não era afetada.</sub>
